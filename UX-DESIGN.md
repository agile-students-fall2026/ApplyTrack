# User Experience Design — ApplyTrack

ApplyTrack is a mobile-first web application for tracking internship and job applications, recruiting stages, events, interviews, and outcomes.

## Mobile wireframes

### Authentication

#### Welcome

![Welcome](ux-design/prototype/welcome.png)

Entry screen for new and returning users; offers sign-up and login navigation.

#### Log In

![Log In](ux-design/prototype/log-in.png)

Allows an existing user to enter credentials, recover a password, or switch to sign-up.

#### Sign Up

![Sign Up](ux-design/prototype/sign-up.png)

Collects the information needed to create an ApplyTrack account.

#### Forgot Password

![Forgot Password](ux-design/prototype/forgot-password.png)

Collects an email address for password recovery.

#### Reset Password

![Reset Password](ux-design/prototype/reset-password.png)

Allows the user to choose a new password.

### Applications

#### Home

![Home](ux-design/prototype/home.png)

Shows a summary of upcoming events and recent applications, with navigation to all major sections.

#### Dashboard

![Dashboard](ux-design/prototype/dashboard.png)

Lists tracked applications and provides access to sorting, adding applications, archived entries, and application details.

#### Add Application

![Add Application](ux-design/prototype/add-application.png)

Form for recording a new job or internship application, including position, employer, contact, and notes.

#### Application Details

![Application Details](ux-design/prototype/application-details.png)

Shows one application’s current status, status history, related events, interview rounds, and offer information.

#### Edit Application

![Edit Application](ux-design/prototype/edit-application.png)

Allows the user to revise an existing application record.

#### Archive

![Archive](ux-design/prototype/archive.png)

Shows archived applications and provides a path to restoring entries.

#### Offer Details

![Offer Details](ux-design/prototype/offer-details.png)

Displays or records offer-related details associated with an application.

### Events and interviews

#### Upcoming

![Add / Edit Interview Round](ux-design/prototype/add-edit-interview-round.png)
